# L4NTrak 3.4.4

Install this patch over 3.4.3 on both your Android phone and Linux PC. Existing package identity, signing certificate, accounts, projects and attachments are retained.

- **Visible Sync Now:** Settings has a Devices & sync card above the category tabs. Desktop also has Sync Now in Device pairing. A PC request is delivered through the authenticated pairing catalog; the phone checks both copies even when its Auto Sync is off. Keep both apps open and finish open editors. Existing history-conflict and project-access checks remain.
- **Phone GPS on PC:** fresh phone positions work while stationary and when speed is unavailable. Open Maps on both devices with the same vehicle selected. Location permission and a local paired connection are required. Stale, background, approximate and unauthorized fixes are excluded. Unsent updates retry after a busy transfer, including Location off.
- **Nearby drivers:** Maps has Save nearby settings. Enablement, transport, convoy key and display distance are saved on this device for this account. The saved choice survives navigation and restart; sharing pauses outside foreground Maps and resumes on return. Anonymous packets still omit speed. Private friend sharing remains a separate per-session opt-in.
- **Trak AI:** general knowledge questions are no longer limited to garage or map records. Explicit music requests run through app controls before model inference, including play, pause, next, previous, volume and now-playing. Android uses active media sessions / media keys; Linux uses MPRIS players. Commands report requests or failures rather than inventing successful playback. General conversation still needs an installed local model or a reachable paired PC. Offline guidance now states its scope for unrelated questions instead of returning an unrelated workshop answer.
- **Phone AI fallback:** Prefer paired PC uses the saved phone model and the phone-local endpoint when the PC is disconnected or its request fails. Phone only works independently of the PC. The engine choice is stored per account on this device; the fallback model can be saved separately. The paired-PC model warm-up action is supported.
- **3D spoilers:** the built-in sedan spoiler and custom spoiler objects follow the trunk hinge while preserving their closed placement, rotation and offsets. Unrigged imported bodies retain their existing behavior.
- **Garage main photos:** bounded frames use contain sizing so portrait, square and wide photos remain inside the card without cropping. Conflicting square/max-height rules no longer cut the image outside its panel.

- **Linux update handoff:** detects installers that exit immediately, tries available system installers with a clean runtime environment, and provides explicit Install in terminal and Save verified DEB recovery buttons. The backup and hash checks apply before launch; a delegated launch is reported as requested, not proof of a visible window.

Automated tests use controlled model, media, location and transport adapters where hardware/services are unavailable. Actual Android/Linux installation, GPS delivery, Wi-Fi/Bluetooth radios, notification permissions, media playback and local-model answer quality still need testing on your devices. This patch does not add cloud sync.
