# L4NTrak 3.7.0

Open Trak from the mobile navigation or Insights & AI on your PC. Enable the assistant for your account. Draft a route request, save a preference, or check app health using the buttons below the message box. You can edit the request before sending it. Enable memory or app actions in Personalization to use those features. Local model conversations require a configured Ollama model. Optional team review adds a reviewer and editor pass.

Open the star in the toolbar or press Alt+J for Quick Access. Pinned and recent pages appear first. Type a page name to search and press Enter to open a single match. Expand Customize shortcuts and layout to edit your pins. Invited browser users see shortcuts for the shared vehicle.

Android users can install over 3.6.0. Linux users can install the new DEB. Windows users should quit the host and extract the whole ZIP into a fresh folder before launching Start L4NTrak.cmd. Safari and other invited browsers receive the shared UI by updating their Windows or Linux host and reloading the page. Personal Trak profiles remain on the signed-in native device.

Automated checks cover native and invited-browser Quick Access, editable request starters, memory isolation, conversation history, permission-gated commands, and six browser-host integration cases including HTTPS and session revocation. Physical GPS, vehicle audio, and on-device model latency still require hardware testing.
